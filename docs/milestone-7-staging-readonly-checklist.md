# M7 staging verification checklist — read only

Prepared locally. **None of these VPS checks has been executed.** Obtain explicit approval identifying the existing Ubuntu 24.04 staging host before connecting. Preserve `gos-cert.org` and `api.gos-cert.org`. Confirm actual paths, users, service names, PHP binary and socket; template values are not discovered infrastructure.

Use an existing authorized operator account. Record sanitized observations only. Do not copy environment contents, cookies, session payloads, customer records, private media, credentials or unredacted configuration/logs into the report.

| Area | Read-only inspection | Acceptance / evidence to record |
| --- | --- | --- |
| Host and listeners | `lsb_release -ds`, `uname -r`, `uptime`, `df -h`, `free -h`, `ss -lntp`; identify actual deployment symlink with `readlink -f` | Ubuntu release, resource headroom, current release; Next/internal API listeners bound to loopback. Verify existing firewall rules with `ufw status verbose` or the installed firewall's list command. |
| Nginx | `nginx -t`; privately inspect effective configuration and enabled domain files, redacting any inline secrets | Correct TLS virtual hosts, frontend upstream and API public root/socket; private storage/dotfiles inaccessible; no public alias to originals. No shared cache of admin, quotation or private-media responses. Confirm existing request/upload limits, not new values. |
| PHP-FPM | Identify installed binary and exact pool; configuration test mode (`php-fpm<version> -t`), service status and private pool inspection | Correct runtime/extensions, pool user, socket ownership/mode and Nginx access; writable storage/bootstrap cache only; errors hidden from visitors. Record effective memory/upload/post limits and encrypted database-session configuration without secret values. |
| systemd | `systemctl status <actual-unit> --no-pager`; `systemctl show <actual-unit> -p User -p Group -p MainPID -p FragmentPath -p ActiveState -p SubState -p NRestarts`; privately inspect unit and bounded journal | Correct release, Node binary, user, protected environment-file reference, restart/stop behavior and write paths. Do not print environment values or unredacted journals. No unexpected restart loop. |
| MySQL | Use an existing protected defaults file/login path; `SELECT VERSION(), CURRENT_USER(), DATABASE();`, `SHOW GRANTS FOR CURRENT_USER;`; privately inspect existing backup status | Correct staging database; runtime account scoped to that database, no global administrative/file privileges. Distinguish runtime permissions from a separately authorized migration account. No DDL/DML, seeding, restore or test database commands on staging. |
| Sessions and cookies | Privately inspect Laravel preflight/config status and cookie attributes from an existing authorized browser session; inspect session table schema and aggregate expiry counts only | Secure, HttpOnly, SameSite=Lax, host-only session cookie; correct lifetime and shared key/config across PHP workers; encrypted session payloads. Admin remains authenticated through media-heavy navigation; no cookies or payloads retained as evidence. HTTP local QA cannot establish these HTTPS staging properties. |
| Proxy headers | Privately inspect Nginx headers/FastCGI parameters, Laravel trusted-proxy list and Next proxy setting | Canonical public host/scheme preserved; visitor-supplied forwarding headers overwritten at the verified ingress. No wildcard trust, forwarded-host trust, or direct public access to an upstream that trusts headers. Confirm actual CDN/proxy topology before enabling trust. |
| TLS | Inspect existing certificate SANs, chain and expiry, renewal timer/status; bounded `openssl s_client` / HTTPS header requests only after connection approval | Both hostnames valid with complete trusted chain and HTTPS redirects. No renewal execution or certificate replacement. HSTS remains absent unless separately reviewed. |
| HTTP policy and SEO | Bounded GET/header checks of existing localized home/catalogue/published detail, `/robots.txt`, `/sitemap.xml`, API site endpoint and known derivative | Staging `noindex, nofollow` retained; canonical/hreflang use correct domains; security headers present. CSP stays **report-only**, not enforced. Do not authenticate, submit quotations or mutate content solely for this read-only checklist. |
| Filesystem | `stat`, `namei -l`, and `getfacl` where available, on confirmed code, environment, private storage, cache and socket paths | Service users can traverse/read required code; only necessary runtime directories writable. Private originals/environment inaccessible to public web roots and unrelated users. No write probes, `touch`, `chmod`, `chown`, symlink changes or `storage:link`. |
| Logs and recovery readiness | Inspect sanitized error counts and existing backup/release manifests | Separate app errors from upstream/socket/session problems; identify last backup and rollback artifact. A listed backup is not a verified restore. No backup, restore, log cleanup or rollback execution under this checklist. |

Record each check as **verified**, **failed** or **not inspected**, with timestamp and sanitized evidence. Any proposed correction requires a reviewable change and separate operational approval. Do not reload/restart services, deploy, migrate, rotate secrets, enable indexing/HSTS/enforced CSP, or begin M8/M9.
